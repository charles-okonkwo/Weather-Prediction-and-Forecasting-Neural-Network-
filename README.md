# Weather Prediction and Forecasting using Artificial Neural Network (ANN)

## Overview

This project is a Machine Learning system that uses an Artificial Neural Network (ANN) to predict weather conditions based on historical weather data.

The model analyzes weather patterns and learns relationships between different weather features to generate predictions. The project demonstrates the application of deep learning techniques in weather forecasting.

## Project Objective

The main objectives of this project are:

- To build an Artificial Neural Network model for weather prediction.
- To preprocess and analyze weather datasets.
- To train a neural network to identify patterns in weather data.
- To evaluate the performance of the trained model.

## Artificial Neural Network Architecture

The ANN model consists of:

- **Input Layer:** Receives weather features such as temperature, humidity, pressure, and other weather parameters.
- **Hidden Layers:** Learns complex patterns and relationships from the dataset.
- **Output Layer:** Produces the final weather prediction.

## Installation

Clone the repository:

```bash
git clone https://github.com/charles-okonkwo/Weather-Prediction-and-Forecasting-Neural-Network-.git
```

Navigate into the project folder:

```bash
cd Weather-Prediction-and-Forecasting-Neural-Network-
```

Install required packages:

```bash
pip install -r requirements.txt
```

## Usage

Run the model:

```bash
python main.py
```

The neural network will process the weather data and generate prediction results.
